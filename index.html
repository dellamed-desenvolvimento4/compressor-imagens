Compressor de imagens

Redimensiona e comprime cada imagem para caber no tamanho máximo, mantendo o nome do arquivo. Tudo é processado no seu navegador: nenhuma imagem é enviada para a internet.

Configurações

Deixe um dos lados vazio para manter a proporção pelo outro.
Avançado
Se não couber nem com a qualidade mínima, a resolução cai pelo fator a cada tentativa, até o lado mínimo.

    Ao mudar uma configuração, as imagens já adicionadas são processadas de novo automaticamente.
